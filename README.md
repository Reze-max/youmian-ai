## 8. 快速开始（演示前 5 分钟）

**Step 1：打开原型**

- 双击 index.html（**单文件自包含 207 KB**，无需联网即可打开）
- 推荐浏览器：Chrome 120+ / Edge 120+
- 不需要任何依赖安装

**Step 2：（可选）配置 API key**

- 默认 config.js 中已硬编码 M3 API key（PM 面试开箱即用）
- 如果担心 key 泄露，临时注释掉 index.html 中的 <script src="config.js"></script> 即可回退到 mock 模式
- 详细安全说明见  2-PRD.md §11.7

**Step 3：演示路径（5 分钟）**

1. **P01 → P02 → P05**（1 分钟）：演示简历上传 + M3 经历包装
2. **P06 → P07**（2 分钟）：选公司 + 压力级别 + 跑 3-5 轮对话（流式输出）
3. **P08**（1 分钟）：6 维雷达 + 考点 + 回答 + 诚实反馈
4. **P09 → P12**（1 分钟）：能力曲线 + 订阅页

**Step 4：遇到问题**

- **CORS 错误**：浏览器不允许直连 → 已在 config.js 中配 Qwen-Plus 备选 + 自动降级到 mock
- **JSON 解析失败**：M3 偶发 → 自动重试 1 次 + 二次 prompt 强制重评
- **白屏**：检查控制台报错 → index.html 完全自包含，理论上 0 依赖

**5 分钟演示话术（PM 面试现场用）**：
