## 3. 调研方法

- **访谈对象**：5 位目标用户（3 名校招 + 2 名在读）
- **访谈形式**：腾讯会议 + 录音 + 速记
- **时长**：30-40 分钟 / 人
- **前置问卷**：5 题（身份 / 目标岗位 / 面试场次 / 准备方法 / 反馈来源）
- **访谈提纲**：10 题 STAR 骨架（流程 / 准备 / 卡壳瞬间 / 反馈来源 / AI 期待 / 工具槽点 / 付费意愿 / 风格差异 / 面经痛点 / 必备功能）

## 5. 痛点矩阵

| 痛点编号 | 痛点描述 | 频率 | 强度 | 访谈原话引用 | 映射功能 |
| --- | --- | --- | --- | --- | --- |

| P2 | 不同公司风格差异大 | 4/5 | 强 | "字节面试官节奏快，腾讯更注重思考过程"（小李） | 分公司风格模拟 |
| **P3** | **跨专业 / 学术背景难以转化为产品经历** | **4/5** | **强** | **"用信息系统的思维答产品岗的题"（小王）/ "用数据分析师的思路答产品经理的题"（小刘）/ "把学术语言转化为产品语言"（小张）** | **经历包装 + 能力映射**（W1 v0.2.3 新增） |
| P4 | AI 工具反馈笼统 | 5/5 | 强 | "AI 永远在'夸你'，不会真的告诉你'你挂了'"（小刘） | 严格评分 + 具体改进建议 |

| **P7** | **面试紧张 / 被追问时慌** | **3/5** | **中** | **"前一天晚上紧张到失眠，早上喝了两杯咖啡"（小刘）/ "被追问时容易慌"（小张）** | **压力模拟面试**（W1 v0.2.3 新增） |

### 5.1 痛点核心洞察

- **P1 + P4**：同一痛点的两个维度——"缺乏反馈" + "AI 反馈不诚实"——直接对应优面AI 的核心差异化（敢说真话）
- **P2**：直接支持 PRD §5 人设库的产品价值
- **P3**：**新发现痛点**——4/5 提及，强度都是"强"——意味着"跨专业 / 学术背景学生"是优面AI 的**重要细分用户群**
- **P5 + P6 + P7**：用户深层次需求——失败案例、进步追踪、压力模拟——PRD 之前没明确覆盖

## 6. 关键洞察

### 6.1 假设验证结果

#### ✅ H1：真实面试官反馈获取是最大卡点 —— 验证通过

- 5/5 用户均提及，强度均为"强"
- 核心表述："面完就像开盲盒"、"像考试不知道分数"、"拒信都是系统自动发的模板"

#### ✅ H2：用户愿为结构化复盘付费 —— 验证通过

- 5/5 用户表示愿意付费，预算 **30-120 元/月**
- **价格区间**：在读学生 30-60 元/月，应届校招 50-120 元/月
- **付费意愿排序**：
  1. 面试评分 + 具体改进建议（最高）
  2. 分公司风格模拟
  3. 进步追踪功能

#### ✅ H3：用户偏好分公司差异化风格 —— 验证通过

- 4/5 用户明确感受到不同公司的面试风格差异
- **4 家公司风格画像**（直接喂给 PRD §5.2）：

| 公司 | 面试风格 | 典型问题类型 |
| --- | --- | --- |
| **字节** | 压力测试型，节奏快，连环追问 | 数据驱动、增长逻辑、结论先行 |
| **腾讯** | 系统思考型，注重底层逻辑 | 用户需求定义、思考过程、判断依据 |
| **美团** | 业务落地型，关注商业化 | ROI、核心指标、业务流程 |
| **小红书** | 内容感知型，看重网感 | 用户洞察、内容生态、创作者运营 |

### 6.2 新机会发现

| 机会点 | 描述 | 来源 |
| --- | --- | --- |
| **心理安全感需求** | 用户（尤其面试失败后）需要"被看见的进步"——通过评分、雷达图、进步轨迹缓解焦虑 | 小刘（统计研一·焦虑组） |
| **学术 → 产品视角转换** | 研究生 / 跨专业学生需要将学术研究经历转化为产品岗竞争力（小王·信管；小张·信管研二；小刘·统计） | 3 个研究生用户 |
| **进步可视化** | "看到自己从 50 分 → 55 分" 比 "刷了多少题" 更缓解焦虑 | 多个用户 |
| **失败案例参考** | 用户对"挂掉的人都错在哪里"的需求显著 | 小王、小张 |
| **AI 提示回答的精准化** | 用户希望"卡壳时给思路提示而非直接给答案" | 小陈、小李、小张 |

## 7. 调研结论

### 7.1 优面AI 产品方向验证

- ✅ **方向正确**：5/5 用户痛点都对应"AI 模拟面试"能解决的核心问题
- ✅ **核心差异化（敢说真话 + 结构化）** 已被用户痛点验证
- ✅ **付费意愿有保障**：30-120 元/月
- ✅ **价格信号**：用户可接受价格 **30-120 元/月**（PRD 04 数据预估需更新）

### 7.2 对 PRD 的关键输入（W1 v0.2.3 待更新）

1. **5 个用户画像**已就位（§4）→ 替换 PRD §2.1 占位
2. **7 个痛点**已结构化（§5）→ 替换 PRD §2.2 占位
3. **4 家公司风格画像**（§6.1）→ 直接喂给 PRD §5.2 内容维度表
4. **价格区间 30-120 元/月** → 喂给 PRD 04 数据预估
5. **4 个新发现痛点**（P3 / P5 / P6 / P7）→ PRD 需新增对应功能

### 7.3 MVP 优先级调整

| 痛点 | PRD 优先级 | 说明 |
| --- | --- | --- |
| P1 + P4 敢说真话 | **V1.0 核心** | 不变 |
| P2 分公司风格 | **V1.0 核心** | 不变 |
| P3 跨专业经历包装 | **V1.0 新增** | 4/5 提及，强 |
| P6 进步追踪 | **V1.0 升级** | 从原 V2 升级到 V1.0（用户心理需求强烈） |
| P7 压力模拟 | **V1.0 新增** | 字节式"连环追问"风格 |
| P5 失败案例库 | **V1.5 备选** | 3/5 提及，强度中 |
